# 亂打輸入法

在電腦上「照大千鍵盤亂打注音」，由本機小 AI 幫你糾錯、預測中文候選。  
掛在 **小狼毫（Rime）** 底下使用。

目前版本：**0.1.3-Beta**（測試預覽，功能還會再調整）

---

## 安裝前請先準備

1. **小狼毫**（Windows 版 Rime）  
   下載：https://rime.im/download/
2. **Python 3.11 或更新**  
   下載：https://www.python.org/downloads/  
   安裝時請勾選 **Add python.exe to PATH**

---

## 安裝步驟（第一次用也可以）

1. 到本專案的 [Releases（發行頁）](https://github.com/spboxer3/luanda-ime/releases) 下載兩樣東西：
   - 程式壓縮檔（原始碼 zip，或直接下載整個專案）
   - **`luanda_bopomofo_int8.zip`**（模型，一定要有）
2. 把程式解壓到任意資料夾。
3. 把 `luanda_bopomofo_int8` 資料夾解壓後，放在與 **`install.bat` 同一層**。
4. 雙擊 **`install.bat`**，依畫面提示完成安裝。
5. 若沒有自動部署：在工作列右下角找到小狼毫圖示 → **右鍵 → 重新部署**。
6. 按鍵盤 **F4**，或 **Ctrl + \`（數字鍵 1 左邊那顆）**，選 **「亂打輸入法」**。

裝好後資料夾大致會像這樣：

```text
（某個資料夾）/
├── install.bat
├── start_server_hidden.vbs
└── luanda_bopomofo_int8/     ← 從發行頁下載解壓來的模型
```

## 怎麼打字

| 你做的事 | 會發生什麼 |
|----------|------------|
| 用大千鍵位打注音 | 出現中文候選（約 2 個鍵就開始補字） |
| **空白鍵** | 輸入一聲 |
| **Enter** | 選定目前反白的候選字 |
| 單獨按一下 **Shift** | 組字中改成「英文按鍵」候選（再按可切回） |
| **Shift + ,**／**Shift + .** | 輸入 **，**／**。**（大千標點在 Shift 層） |
| **Shift + /**、**Shift + ;** 等 | ？、：、「」……等常用標點 |
| **BackSpace** | 一次刪掉一整個音節 |
| 選過的字詞 | 會記進慣用詞，之後同鍵碼優先出現 |

## 常見問題

**Q：候選字都沒出現？**  
A：請再雙擊一次 `start_server_hidden.vbs`（它會在背景啟動本機預測服務）。重開機後若又沒字，通常也是再執行一次即可。

**Q：選單裡找不到「亂打輸入法」？**  
A：確認 `install.bat` 有跑完，並對小狼毫執行「重新部署」，再用 F4 切換方案。

**Q：可以跟原本的注音一起用嗎？**  
A：可以。它只是小狼毫裡多一個方案，用 F4 切換即可。

---

## 解除安裝

1. 雙擊 **`uninstall.bat`**
2. 小狼毫圖示 → 右鍵 → **重新部署**
3. （可選）在工作管理員結束仍在執行的 `python`／亂打相關程式
